# Portfolio (Next.js + Sanity + Motion)
1. `npm i`  2. copy `.env.example` to `.env.local` and add your Sanity project ID (sanity.io/manage)
3. `npm run dev` then open `/studio`, add Profile, Projects, Tech, Highlights, then `/`
4. Add your site URL to Sanity CORS origins (with credentials). Deploy on Vercel.
5. Optional: Sanity webhook to a revalidate route for instant updates (pages auto-refresh every 60s).
Animation skills: `npx skills add emilkowalski/skills`, then run find-animation-opportunities, improve-animations, review-animations.
